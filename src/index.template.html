使用与发射说明

怎么把 WAV 发出去？

把生成的 WAV 用播放器（或 SDR 软件的音频发送通道）送到电台的话筒/数据输入，用 SSB 发射：

设置取值
模式USB（上边带）或 AM
业余 20 m 段14.230 MHz 附近，USB 拨号 14.2281 MHz
音频带宽≥ 2.6 kHz，关掉语音压缩 / 降噪
驱动电平ALC 不起表，峰值不超过额定功率

USB 发射时，1900 Hz 副载波会落到 拨号频率 + 1.9 kHz；接收端把 SSB 解调回音频后用传真解码软件（fldigi、JWX、HF-FAX 等）还原图像。

这套参数是什么标准？

WMO/IMO 模拟气象传真（radio facsimile / WEFAX）：视频信号以 1500 Hz 表示白、2300 Hz 表示黑，正频移对应黑；副载波中心 1900 Hz，占用带宽 2550 Hz。每行 500 ms（120 行/分），IOC 576 即一鼓 576 行、鼓周期 288 秒，对应约 3.75 ms 的像素周期。

发射格式为：起始音（可选，300 Hz / 5 s）→ 相位行（黑条占行周期 5 %，其余全白，用于接收机锁定行起点）→ 图像行 → 停止序列（黑行 + 450 Hz 停止音）。

常见问题

接收端说图像位置不对？确认相位信号已开启（默认 5 %），并且接收机的相位/行同步已锁定；起始音只在部分台站使用。

图像偏灰、对比度差？打开“自动对比度”，或先把扫描件调成纯黑纯白再编码。天气图不要开抖动。

输出有削顶？把输出电平降到 0.6–0.7。编码结果里会显示峰值与实际削顶采样数。

平板/手机上存不下文件？点“分享到…”直接发送到网盘、邮件或电台软件；桌面浏览器用“保存 WAV”。

能用 PDF 吗？不能直接解码。请先在系统里把 PDF 页导出成 PNG/JPEG 再拖进来。

单文件离线应用 —— 无服务器、无上传、无依赖。核心编码引擎与 src/hffax.js 完全一致， 已通过 Python 黄金参考实现逐字节比对与 FFT 频谱验证（黑 2300 Hz / 白 1500 Hz / 停止音 450 Hz）。 仅供具备相应许可的业余无线电操作者与气象传真爱好者使用，发射前请确认本地法规与频率授权。
